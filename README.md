# C++ Job Search Engine 🔍

A fast, preference-matching search engine program written in C++ designed to filter, evaluate, and match job opportunities based on personalized user criteria.

## 🌟 Features
* **Preference-Matching Algorithm:** Intelligently filters and ranks job listings according to specific personal preferences and customized parameters.
* **File Data Persistence:** Implements robust file I/O handling to store and retrieve data locally. Databases, user profiles, or session states remain intact between application launches without needing an external database server.
* **Memory Efficiency:** Built strictly in C++ utilizing standard library data structures for optimal memory management and rapid execution times during searches.
* **Interactive CLI:** A clean command-line interface for intuitive navigation, data entry, and database querying.

## 🚀 Getting Started

**Prerequisites:** 
* A standard C++ compiler (e.g., GCC, Clang, or MSVC)

### Installation & Execution
1. Clone this repository to your local machine:
   ```bash
   git clone [https://github.com/MrBinyamin/jobsearch-in-C-.git](https://github.com/MrBinyamin/jobsearch-in-C-.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd jobsearch-in-C-
   ```
3. Compile the source code using your preferred C++ compiler. For example, using g++:
   ```bash
   g++ -o jobsearch main.cpp
   ```
   *(Note: Ensure you include all necessary `.cpp` source files in your compilation command if the project is split into multiple files).*
4. Run the compiled executable:
   ```bash
   ./jobsearch
   ```

## 🛠️ Built With
* **C++** - Core application logic, algorithmic filtering, and memory management.
* **C++ Standard Library (STL)** - For handling dynamic data structures.
* **Fstream Library** - For managing data persistence and local file storage operations.
